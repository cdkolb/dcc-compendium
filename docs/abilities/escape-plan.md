# Escape Plan

!!! info "Quick facts"
    - **Owner:** Carl
    - **Gained:** Book 2, +5 skill level granted by his **Compensated Anarchist** class
    - **Effect:** Reveals hidden doors more readily, and grants access to the **Dungeon
      Locator** — an undocumented system feature even Mordecai had never encountered before
    - **Notable:** Functions more like a fixed perk unlock than a scaling combat skill

!!! quote "AI Commentary (in-voice, written for this wiki — not a book excerpt)"
    "Escape Plan: for the crawler who read the terms of service and found a clause even *we*
    forgot we wrote. Congratulations. You get a secret menu. Try not to tell anyone."

## Overview

Escape Plan functions as the Compensated Anarchist class's substitute for a proper Pathfinder
skill (something several other classes, like Trickster, get outright). Mordecai is genuinely
surprised by it — "Odd. It looks like it's an old skill, but I've never come across it before.
You learn something new every day." Beyond improving hidden-door detection, its real value is
unlocking access to the **Dungeon Locator**, a system feature the game itself doesn't explain:
"It says it offers access to the Dungeon Locator, but it doesn't say what that is or how to
access it." Mordecai happens to already know how to find and read it, despite never having seen
the skill that grants access to it before.

## Scaling

The class card grants a flat **+5 to the Escape Plan Skill** on pick. Unlike the other
Compensated Anarchist skills, the text doesn't frame Escape Plan as something that scales its
effect predictably with level — it reads more like a perk/access-unlock (hidden doors, the
Dungeon Locator) than a stat that multiplies or improves numerically per level. No explicit
per-level formula is given.
