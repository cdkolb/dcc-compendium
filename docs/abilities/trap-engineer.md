## Overview

Trap Engineer is one of several trap/bomb-making skills bundled into Carl's **Compensated
Anarchist** class card (alongside [Bomb Surgeon](bomb-surgeon.md), [Hide in
Shadows](hide-in-shadows.md), [Backfire](backfire.md), and [Escape Plan](escape-plan.md)), picked
on Floor 3 in Book 2. Unlike Bomb Surgeon and Backfire, the text doesn't give Carl an in-scene
moment demonstrating what the skill actually does beyond its name — it's simply listed on the
class card.

## Scaling

The class card grants a flat **+1 to the Trap Engineer Skill** on pick. The Compensated Anarchist
class also grants **+5% skill progression speed in all trap-making and bomb-making skills**,
which applies here. No book text yet clarifies a specific per-level effect.
