# Items & Tattoos

Master loot catalog: weapons, armor, potions, scrolls, tomes, and tattoos. Full pages exist for
unique/plot-relevant items from Book 1; common or one-off items are listed in the table below.
Any full page should include a **Scaling** section whenever the book describes how the item's
effect changes with a relevant skill level or stat, and a **Future Enhancements** section
whenever a later book physically upgrades or enhances the item (e.g. a sharpening stone,
enchantment stacking, a crafting event) — as a placeholder note pointing to the book/chapter if
that book hasn't been processed yet, or filled in fully once it has. Any item named in a
full-page character's Quick Facts box must itself have a full page here, not just a table row.
