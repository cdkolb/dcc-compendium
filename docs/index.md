# Dungeon Crawler Carl Compendium

A personal reference for the *Dungeon Crawler Carl* series by Matt Dinniman — built to be deeper
and less cluttered than the existing fan wikis.

This is a work in progress. Most sections below are placeholders; two example pages
(**[Carl](characters/carl.md)** and **[Level 1](floors/level-01.md)**) are filled in to show
the target depth and style.

## Sections

- **[Characters](characters/index.md)** — crawlers, NPCs, bosses, deities, dungeon admins
- **[Factions](factions/index.md)** — Syndicate organizations, guilds, parties
- **[Dungeon Floors](floors/index.md)** — one page per level: layout, mechanics, notable events
- **[Game Mechanics](mechanics/index.md)** — boxes, feats, classes, races, status effects, currency
- **[Items & Tattoos](items/index.md)** — loot catalog
- **[Timeline](timeline/index.md)** — chronological events across the series
- **[Glossary](glossary/index.md)** — crawler-speak and Syndicate terminology
