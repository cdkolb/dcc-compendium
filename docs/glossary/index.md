# Glossary

Crawler-speak and Syndicate terminology, as used in Book 1.

**Achievement** — A system-generated notification, usually comedic or crude, awarded for a
notable in-game action; nearly always grants a loot box.

**Benefactor Box** — A patron-exclusive loot box that can contain technology from the patron's
home world, unobtainable any other way in the dungeon.

**Boss Box** — The loot box awarded for landing the killing blow on a boss; its tier matches the
boss's tier (Bronze for Neighborhood, Silver for Borough, etc.).

**Crawler** — The Syndicate's term for a human (or other species) contestant who has entered the
World Dungeon.

**Crawler Notification** — A system message visible only to the crawler it concerns, as opposed
to a System Message (visible to everyone on the floor).

**Fog of War** — The parts of the minimap a crawler hasn't personally explored yet; rendered
without detail even when technically within minimap range.

**Hotlist** — A 10-slot quick-access bar for spells, potions, and items, usable with a single
mental click.

**Kua-tin** — See the [Kua-Tin & The Bloom](../species/kua-tin-and-the-bloom.md) species page.

**Level Collapse** — The point at which a dungeon floor's countdown timer expires; anyone still
present forfeits everything, crawler included.

**Neighborhood Boss** (and the rest of the boss ladder) — See
[Boss Tier Ladder](../mechanics/boss-tier-ladder.md).

**Non-Combatant NPC** — An NPC classification (like [Mordecai](../characters/mordecai.md)) that
cannot be attacked and typically serves a guide/vendor role.

**Patron** — Usually a corporate sponsor (rarely an individual) who purchases loot boxes for a
specific crawler, generally after that crawler accumulates enough Favorites. See
[Ratings & Viewership](../mechanics/ratings-and-viewership.md).

**Red-tagged / White-tagged** — A creature's minimap/name-tag color coding indicating hostility:
red for aggressive/dangerous, white for docile or non-hostile.

**Safe Zone / Safe Room** — An area where combat cannot occur and loot boxes can be opened; all
Tutorial Guilds qualify.

**Snick** — Fan-made short video content depicting a crawler from any character's point of view;
described as "kind of like a fan fiction, but it's a video." Can be entirely fabricated
("Pork Boy Snick") yet still go viral and affect a crawler's public reputation.

**Solar** — The kua-tin/Syndicate unit of time roughly analogous to a year, used in official
legal/administrative contexts (e.g. the 50-Solar deadline for a planet's resource-rights appeal).

**Syndicate Standard** — The universal language the dungeon's translation system renders all
speech into/from; crawlers perceive it as their native tongue.

**System (the)** — Shorthand crawlers use for the dungeon's overall rules/notification engine;
distinct from "the AI," which usually refers to the specific narrating voice.

**Tutorial Guild** — A guildhall, seeded on Floors 1–3, where a Non-Combatant NPC unlocks a new
crawler's inventory/menu access and explains core mechanics.

**Views / Followers / Favorites** — See [Ratings & Viewership](../mechanics/ratings-and-viewership.md).
